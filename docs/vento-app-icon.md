# Vento Home-Screen Icon

Generated with the built-in imagegen tool using `public/brand/vento-logo-counter.jpg` as the brand reference.

## Artwork Prompt

Use case: logo-brand. Asset type: production iPhone home-screen app icon for Vento Cafe & Market. Use the established leaf/coffee-bean and three flowing wind strokes as the reference. Create one square bitmap with an opaque, full-bleed forest green background (#204536). Center a large emblem with warm ivory wind ribbons, subtle satin relief, and a soft metallic gold leaf/bean pointing up-right. Keep a clean silhouette and a generous safe margin for small home-screen sizes. No letters, wordmark, border frame, rounded outer corners, devices, props, or watermark.
